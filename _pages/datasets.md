<a href="https://github.com/ceios/ceios"> Cyber-enabled influence operation dataset </a>
======
This repository contains a database of real-world cyber-enabled influence operations (CEIOs). The combined operations are described and visualised in a unified CEIO model. Our model combines the MITRE ATT&CK and DISARM frameworks, which denote cyberattack and influence components, respectively. The MITRE AttackFlow Builder application is modified to include DISARM framework objects and enable CEIO modelling with the unified framework.
