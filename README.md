# hxnguyen.github.io

Personal academic website of Hung X Nguyen, built by GitHub Pages with Jekyll.

- `index.html` is the homepage.
- `_pages/*.md` are the other pages (Publications, Students, Datasets, Code, About). Edit them as
  Markdown; they render with the site layout automatically.
- `_layouts/archive.html` is the page layout, `_includes/site-bar.html` and
  `_includes/site-footer.html` are the header and footer, and `assets/css/site.css` is the
  stylesheet shared by every page.
- `images/` and `files/` hold the images and PDFs the pages link to.
